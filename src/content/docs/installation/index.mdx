SuperDucky 目前只通过 **Microsoft Store** 发布。商店版本由 Windows 负责安装和更新,不需要先安装 Node.js 或其他运行环境。

## 获取

| 项目 | 内容 |
|------|------|
| 获取方式 | Microsoft Store |
| 商店标识 | `9NDBTDKQBX30` |
| 商店里的名称 | 中文“超级丫丫”,英文 SuperDucky |
| 适用系统 | Windows 10 / 11 |

1. 打开 Microsoft Store,搜索“超级丫丫”或 SuperDucky,或直接打开商店标识为 `9NDBTDKQBX30` 的页面。
2. 点击**获取**,等待安装完成。
3. 从开始菜单启动 SuperDucky。

## 更新

商店会自动更新应用,也可以在 Microsoft Store 的“库”里手动检查更新。每个版本的变化见[版本更新说明](/release-notes)。

## 安装之后

- 第一次启动会进入初始化向导,见[首次启动](/quick-start/first-launch)。
- 应用的设置、套件和缓存保存在应用的数据文件夹里。具体位置显示在“设置 → 基础配置 → 配置和数据位置”,更多说明见[遥测与隐私](/faq/data-and-privacy)。每个游戏的数据在其中的 `games/<游戏>/` 下,互不干扰。

## 前置条件

- 通过 Steam 安装好你要管理的游戏(逃离鸭科夫或深空当铺)。
- 想使用模组市场订阅创意工坊模组时,需要 Steam 客户端处于运行状态。
