SuperDucky 可以通过 **Microsoft Store** 获取,也可以从 **GitHub Releases** 下载最新版本和历史版本。商店版本由 Windows 负责安装和更新,不需要先安装 Node.js 或其他运行环境。

## 获取

| 项目 | 内容 |
|------|------|
| 获取方式 | Microsoft Store,或 [GitHub Releases](https://github.com/HagiCode-org/SuperDucky.Release/releases) |
| 商店标识 | `9NDBTDKQBX30` |
| 商店里的名称 | 中文“超级丫丫”,英文 SuperDucky |
| 适用系统 | Windows 10 / 11 |

1. 打开 Microsoft Store,搜索“超级丫丫”或 SuperDucky,或直接打开商店标识为 `9NDBTDKQBX30` 的页面。
2. 点击**获取**,等待安装完成。
3. 从开始菜单启动 SuperDucky。

## 从 GitHub 下载最新和历史版本

除了 Microsoft Store,你也可以在 [SuperDucky.Release](https://github.com/HagiCode-org/SuperDucky.Release/releases) 的发布页下载任意版本,包括最新版本和以前的历史版本。

1. 打开 [https://github.com/HagiCode-org/SuperDucky.Release/releases](https://github.com/HagiCode-org/SuperDucky.Release/releases)。
2. 选择需要的版本。列表最上面的是最新版本,往下是历史版本。
3. 在该版本的 **Assets** 里下载安装包并运行。

从 GitHub 下载的版本不会通过 Microsoft Store 更新。需要新版本时,请回到发布页下载。每个版本的变化见[版本更新说明](/release-notes)。

## 更新

通过 Microsoft Store 安装的版本由商店自动更新,也可以在 Microsoft Store 的“库”里手动检查更新。从 GitHub 下载的版本需要自己到[发布页](https://github.com/HagiCode-org/SuperDucky.Release/releases)获取新版本。每个版本的变化见[版本更新说明](/release-notes)。

## 安装之后

- 第一次启动会进入初始化向导,见[首次启动](/quick-start/first-launch)。
- 应用的设置、套件和缓存保存在应用的数据文件夹里。具体位置显示在“设置 → 基础配置 → 配置和数据位置”,更多说明见[遥测与隐私](/faq/data-and-privacy)。每个游戏的数据在其中的 `games/<游戏>/` 下,互不干扰。

## 前置条件

- 通过 Steam 安装好你要管理的游戏(逃离鸭科夫、深空当铺或以撒的结合)。
- 想使用模组市场订阅创意工坊模组时,需要 Steam 客户端处于运行状态。
