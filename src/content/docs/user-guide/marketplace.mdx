“模组市场”用来找到新的模组并安装它们。市场有几种来源,每种来源是一个**提供商**,在页面顶部切换。

| 提供商 | 说明 | 适用游戏 |
|--------|------|----------|
| **Steam 创意工坊** | 浏览、搜索、订阅和取消订阅创意工坊模组 | 逃离鸭科夫、深空当铺 |
| **本地文件夹** | 从一个文件夹里的 ZIP 压缩包安装模组 | 两个游戏 |
| **NuGet 源** | 从 NuGet 源获取模组 | 仅逃离鸭科夫 |

:::note
使用 Steam 创意工坊提供商时,需要 Steam 客户端处于运行状态。如果提示“没有找到可用的模组来源”,先启动 Steam,再重试。
:::

## Steam 创意工坊

打开页面后默认显示**热门模组**。在搜索框里输入关键词、标签或作者名后点击**搜索**,会显示搜索结果。

- **排序**:相关度、最近更新、最早更新、最高评分、最低评分、最多订阅、最少订阅、最多下载。
- **视图**:大图模式(带预览图和详细信息)、普通模式和极简模式(列表,每屏更多内容)。默认视图和每页数量可以在“设置 → 模组市场”里设置,在市场页面里仍可临时切换。
- **卡片**:显示作者、评分、订阅数和更新时间。点击**查看详情**可以看到预览截图、说明和依赖。

### 订阅与依赖

- 点击**订阅**,Steam 会下载这个模组。已订阅的模组显示“已订阅”,有新版本时显示“可更新”,点击**更新**即可。
- 点击**退订**取消订阅。
- 模组详情里的**依赖**面板列出每个依赖是“已安装”“缺失”还是“未知”,并能一次**订阅缺失的依赖**。如果发现循环依赖,也会标出来。
- 订阅之前,如果这个模组的订阅人数很少,或作者出现在你的屏蔽名单里,会按“订阅安全”的设置处理,见下文。

订阅后的模组下载到创意工坊文件夹,回到“模组管理”点击**刷新**就会出现在“未分组”里。

### 订阅安全

在“设置 → 模组市场 → Steam 市场设置”里可以调整:

- **最低订阅人数**:订阅人数低于这个值的模组不再出现在列表、搜索和热门里,`0` 表示关闭。你已订阅的模组始终可见。
- **屏蔽的作者**:输入 17 位 Steam ID 或 `steamcommunity.com/profiles/` 链接,这位作者的模组不会在市场里出现。不支持自定义主页链接(`/id/...`)。
- **订阅前确认**:订阅开始前先显示订阅人数和作者的历史记录,出现提示时仍然可以继续订阅。
- **Steam 模组自动更新**:自动检测已订阅模组的更新并触发下载,“更新历史”里可以查看记录。

## 本地文件夹

如果模组是以 ZIP 压缩包形式拿到的,用这个提供商批量安装:

1. 点击**选择文件夹**,选中存放 ZIP 的文件夹。**每个 ZIP 就是一个模组**。
2. 列表会显示每个压缩包里读到的模组 ID、版本和文件名。读不到合法清单的压缩包会显示“无法安装”以及原因。
3. 点击单个压缩包旁的**安装**,或点击**全部安装**。
4. 安装结果分为“已安装”“已替换”“已跳过”“失败”,页面底部有汇总。如果和已有模组冲突,会显示“与 xxx 冲突”。

压缩包会先检查模组的标识(逃离鸭科夫读 `info.ini`,深空当铺读 `manifest.xml`),安装前再核对一次;模组最终放进以它的 ID 命名的文件夹里。深空当铺正在运行时会拒绝安装。

## 逃离鸭科夫专属:NuGet 与 BML

- **NuGet 源**:可以在“设置 → 模组市场”里启用或禁用。
- **BML 导入**:在套件管理里导入 BML 的配置,见[加载顺序与套件](/user-guide/load-order-and-profiles)。
