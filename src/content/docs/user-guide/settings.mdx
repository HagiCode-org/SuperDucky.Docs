在导航栏点击**设置**。页面左侧是分类列表,右侧是对应的选项。修改后留意页面上的保存状态(保存中、已保存或保存失败)。

## 基础配置

- **显示语言**:选择整个应用使用的语言,共十种,见下文[显示语言](#显示语言)。更改后立即生效,重启后保持不变。
- **配置和数据位置**:显示当前使用的配置文件和数据目录,方便备份或排查问题。
- **隐私与遥测**:查看和控制数据采集,见[遥测与隐私](/faq/data-and-privacy)。

## 游戏选项

这一页的内容针对**当前游戏**,切换游戏后会显示那个游戏的设置。

- **自动探测路径**:让 SuperDucky 自己找到游戏文件夹,探测后请检查一遍。
- **模组本地仓库**:打开或关闭模组本地仓库,设置比对间隔,并可以立即检查。见[模组本地仓库](/user-guide/mod-local-repository)。
- **本地 Mod 文件夹**:手动安装的模组所在的文件夹。
- **Steam Workshop 文件夹**:Steam 创意工坊自动下载模组的位置。
- **游戏数据路径**(逃离鸭科夫)/ **存档目录**(深空当铺)/ **游戏数据目录**(以撒的结合):用于把模组配置同步到游戏。
- **启动游戏等待时间**:从 SuperDucky 启动游戏时,它会暂时关闭自己的 Steam 连接,避免和游戏冲突,游戏启动后再恢复。这个时间就是恢复之前等待的秒数。

### 怎么设置启动等待时间

必须确保点击启动后,**游戏在这段时间内已经完全启动**。等待时间太短时,Steam 连接还被 SuperDucky 占用,Steam 会提示“游戏正在运行”而无法启动游戏。参考值:

| 环境 | 建议 |
|------|------|
| SSD,网络良好 | 5–15 秒 |
| 机械硬盘,网络一般 | 20–30 秒 |
| 网络较慢或配置较低 | 30–45 秒 |
| 网络很差 | 45–60 秒 |

## 安装向导

可以**重置向导状态**,下次启动时重新进入初始化向导。重置只作用于当前游戏,重新初始化之后才能继续使用。

首次启动时的显示语言、协议和快速检查不属于某个游戏,重置向导不会让它们再次出现。已经通过的快速检查也不会因为重置而需要重做。见[首次启动](/quick-start/first-launch)。

## 模组市场

- **默认视图模式**:大图、普通或极简。
- **每页数量**:自动或固定数量。
- **Steam 市场设置**:自动更新、更新历史、缓存时长和订阅安全,详见[模组市场](/user-guide/marketplace)。
- **NuGet 市场设置**:启用或禁用 NuGet 源(仅逃离鸭科夫)。

## 调试工具

调整日志级别(DEBUG、INFO、WARN、ERROR)、日志文件轮转和保留数量,打开日志文件夹,导出日志。见[游戏日志](/user-guide/logs)。

## 安全中心

点击应用里的外部链接时,SuperDucky 会先弹出确认对话框。勾选“不再提示此类链接”会把域名加入**受信任的域名**,以后这个域名的链接直接打开。可以在这里查看和移除受信任的域名,或者全部清除。

## 存档图鉴

仅逃离鸭科夫显示这一项,包含图鉴的功能开关和对比属性的排序。
