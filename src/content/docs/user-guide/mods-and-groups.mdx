“模组管理”是 SuperDucky 的主页面。这一页说明如何查找和启用模组、如何用分组组织它们,以及依赖健康检查在做什么。

![逃离鸭科夫的模组管理页面:选中 Combat 分组,显示三个已启用的模组](../img/screenshots/user-guide/duckov-mods-zh-cn/original.avif)

## 模组从哪里来

SuperDucky 扫描两个位置:

- **本地**:你在“本地 Mod 文件夹”里手动放进去的模组,或通过模组市场里的 ZIP 安装的模组。
- **Steam 创意工坊**:订阅后由 Steam 下载到创意工坊文件夹的模组。

卡片上的标签显示来源。新扫描到的模组会进入默认分组“未分组”。想重新扫描时点击右上角的**刷新**。

如果列表是空的,通常是还没有配置路径。点击页面上的“打开设置”,检查[设置](/user-guide/settings)里的模组文件夹。

## 扫描进度

扫描模组期间,页面显示“扫描模组中...”和四个步骤:读取设置、扫描已安装的模组、匹配模组与分组、准备列表。当前步骤会高亮,页面同时显示“第 N 步，共 4 步”。

扫描本身不报告百分比,所以进度是按真实步骤显示的,不是百分比。扫描超过 3 秒后,页面会显示已用时间;超过 10 秒还没结束时,会提示“模组较多时需要更久,一切正常,扫描完成后会显示列表。”

## 查找模组

工具栏提供四种缩小范围的方式:

- **来源**:只看本地或只看创意工坊的模组。
- **状态**:只看已启用或已禁用的模组。
- **搜索框**:按名称、作者或简介搜索,按 `/` 可以快速聚焦。
- **视图**:默认视图、精简视图和单行视图,模组很多时精简或单行更容易浏览。

筛选后点击**启用筛选结果**或**禁用筛选结果**,只会作用于当前看到的模组。没有任何筛选时,这两个按钮是**启用全部**和**禁用全部**。筛选条件让所有模组都被隐藏时,页面会提示并给出“清除搜索和筛选”。

## 分组

分组用来把相关的模组放在一起,例如“战斗”“界面”“商店辅助”。每个分组有自己的颜色和名称,分组的先后顺序同时决定模组的加载顺序(见[加载顺序与套件](/user-guide/load-order-and-profiles))。

- **新建**:点击分组列表上方的“新建”,输入名称。
- **编辑和删除**:先选中分组,再点击分组列表上方的“…”菜单,里面有“编辑”和“删除”。删除一个含有模组的分组时,需要选择把这些模组移到哪个分组。
- **调整分组顺序**:拖动分组左侧的把手,或在同一个“…”菜单里选择“上移”“下移”。
- **默认分组**:“未分组”用来接收新扫描到的模组,不能删除。

想同时查看所有分组的模组,使用[预览结果](/user-guide/load-order-and-profiles)。

## 移动和排序模组

- **拖动**卡片左侧的把手,可以在分组内调整顺序,或拖到别的分组里。
- 卡片的菜单提供:启用/禁用、上移、下移、移动到分组最前面、移动到分组最后、发送到分组、打开文件夹,以及在 Steam 中查看。
- **批量操作**:勾选多张卡片后,出现批量工具栏,可以一起启用、禁用、移到分组,或移到分组最前/最后。按 `Esc` 取消选择。

移动模组之后,页面会提示“您有未保存的更改”,点击**保存更改**才会生效。

## 依赖健康检查

页面顶部的横幅显示当前配置是否健康。SuperDucky 会检查:

| 检查 | 含义 |
|------|------|
| 依赖存在性 | 模组声明的依赖是否已经安装 |
| 依赖启用 | 依赖是否已经启用 |
| 顺序验证 | 依赖是否排在依赖它的模组前面 |
| 循环检测 | 模组之间是否循环依赖 |
| 重名检测 | 是否同时启用了多个同名模组 |

一切正常时显示绿色的“模组配置健康”。发现问题时横幅会显示错误和警告的数量,点击**查看报告**可以:

- 对缺失或未启用的依赖,直接**启用**,或通过 **Steam 订阅**;
- 用**定位依赖**和**定位本体**在列表里找到相关模组;
- 对你明确知道没有影响的问题点**忽略**,以后可以**恢复**。

:::tip
错误会提示“建议修复后再保存”,警告则可以保存。依赖错误可能让游戏无法正常运行,建议先处理。
:::
