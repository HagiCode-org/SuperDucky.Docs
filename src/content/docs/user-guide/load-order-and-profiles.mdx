模组的加载顺序会影响它们的行为。这一页说明顺序是怎么算出来的、怎么预览,以及如何用套件保存多套配置。

## 加载顺序怎么来

把所有分组按从上到下的顺序展开,每个分组内再按卡片从前到后的顺序排列,得到的一条总顺序就是加载顺序,靠前的先加载。因此:

- 调整**分组**的先后,会整体移动这个分组里的模组;
- 调整分组**内部**的顺序,只影响这个分组里的模组;
- 只有**已启用**的模组才会参与加载。

## 预览结果

点击模组管理页面右上角的**预览结果**,所有分组会合并成一个列表,每张卡片带着所属分组的颜色。你可以在启动游戏前确认最终顺序。

![预览结果:所有分组合并显示,卡片按分组着色](../img/screenshots/user-guide/duckov-load-order-zh-cn/original.avif)

预览模式下“启用全部”“禁用全部”和拖动排序都不可用,再点一次**预览结果**即可回到正常模式。如果没有任何已启用的模组,预览会提示先启用一些模组。

## 套件

**套件**是一套完整的模组配置:有哪些分组、每个模组是否启用、顺序是什么。你可以为不同的玩法保存不同的套件,例如“日常”和“测试”,随时切换。

页面顶部的“套件:”下拉框显示当前套件。点击它打开套件管理:

| 操作 | 说明 |
|------|------|
| **新建** | 创建新套件。可以选择“创建空白套件”,也可以“复制自”已有的套件 |
| **重命名** | 修改套件的显示名称 |
| **切换到** | 把选中的套件设为当前套件(“生效中”的标记会移动过去) |
| **删除** | 删除套件。至少要保留一个套件,正在使用的套件不能删除 |
| **BML 导入** | 仅逃离鸭科夫:从 BML 的 `ModGroupConfig.json` 导入分组和启用状态,生成新套件 |

不同的游戏有各自的套件,互不影响。

## 还原历史记录

每次保存套件时,SuperDucky 都会自动留下一个历史版本。点击顶部的**还原历史记录**,可以看到每个版本的时间、分组数、模组数和已启用数量。

选择一个版本并点击**还原**后,它只是被加载到当前的编辑器里,你可以先检查,确认没问题再点击**保存更改**。不满意就不保存,当前已保存的配置不会被改动。

## 保存之后发生什么

“保存更改”把当前套件写入 SuperDucky 自己的数据。要把配置交给游戏,有两条路径,取决于游戏:

- **逃离鸭科夫**:保存时自动把模组配置同步到游戏的数据文件夹。
- **深空当铺**:保存分组和切换套件**不会**写入游戏存档。真正写入发生在**启动游戏**的时候,见[深空当铺](/user-guide/probably-stolen)。

两种情况下,点击左下角的**启动游戏**都会先同步,再通过 Steam 启动游戏。
