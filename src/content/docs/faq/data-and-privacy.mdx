## 数据放在本机哪里

SuperDucky 的设置、套件和缓存保存在应用的数据文件夹里。应用的数据文件夹名为 `superducky`。Microsoft Store 版本是打包应用,Windows 可能把应用写入的 `%APPDATA%/superducky/` 重定向到应用自己的存储里,所以请以“设置 → 基础配置 → 配置和数据位置”显示的路径为准。

其中 `config/settings.json` 是全局设置(语言、遥测开关、自定义路径),每个游戏的模组路径、套件、历史版本和缓存分别在 `games/<游戏>/` 下。“设置 → 基础配置”里的“配置和数据位置”会显示当前使用的位置。

升级自单游戏版本时,旧数据会被迁移到逃离鸭科夫的目录下;迁移前原文件会完整备份到 `migration-backups/<时间>/`,不会被删除或覆盖。

## 遥测

SuperDucky 使用 Microsoft Application Insights 收集**匿名**遥测,用于改进产品:

- **性能数据**:启动时间、页面加载速度、功能响应时间、内存和 CPU 使用情况;
- **功能使用统计**:访问了哪些页面、使用了哪些模组管理功能、套件操作、市场浏览和设置更改;
- **匿名错误报告**:脚本错误、崩溃信息和失败的操作。错误信息发送前会被匿名化,文件路径等个人信息被去掉。

**不收集**的内容:

- 姓名、邮箱、用户名等个人身份信息;
- IP 地址(服务端配置为不记录);
- 精确的文件路径,路径会被替换为 `[MOD_PATH]`、`[STEAM_PATH]` 这样的占位符;
- 跨会话的持久用户标识符,不使用跟踪 cookie。

数据不会出售,也不用于广告定向。

## 查看和关闭

在“设置 → 基础配置”的**隐私与遥测**里可以:

- 查看当前的数据采集状态;
- 禁用数据采集;
- 阅读完整的隐私声明。

## 模组本地仓库的数据

开启[模组本地仓库](/user-guide/mod-local-repository)后,模组的已归档版本保存在本机的 `games/<游戏>/mod-history/` 下,每个模组一个仓库。SuperDucky 只读取 Steam 文件夹和本地 `Mods` 文件夹,从不修改它们,也不会自动删除已归档的版本。

## 关于游戏存档

SuperDucky 只在你保存配置或启动游戏时修改游戏的配置。深空当铺的存档在每次写入前都会备份,见[深空当铺](/user-guide/probably-stolen)。
