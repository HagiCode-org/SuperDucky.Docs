SuperDucky(中文名“超级丫丫”)是一款面向 PC 游戏的桌面模组管理器。装一两个模组很简单。装到几十个以后,就容易找不到、排不对、更新后坏掉,想换一套玩法又怕弄乱。SuperDucky 把这些事放进一个界面里解决。

## 模组装了几十个,怎么不乱?

**答:用“模组管理”页面一处管完,再用分组把它们收拢。**

![SuperDucky 模组管理页面:左侧是分组列表,右侧是已启用的模组卡片](./img/screenshots/user-guide/duckov-mods-zh-cn/original.avif)

- **来源统一**:自动扫描本地 Mod 文件夹和 Steam 创意工坊文件夹,所有模组出现在同一个列表里,卡片上标明来源。新扫描到的模组先进入“未分组”,不会悄悄混进你的配置。
- **快速找到**:按来源(本地 / 创意工坊)、状态(已启用 / 已禁用)筛选,按名称、作者或简介搜索(按 `/` 聚焦搜索框),并提供默认、精简、单行三种视图。
- **一次操作一批**:筛选之后可以只对看到的模组“启用筛选结果”或“禁用筛选结果”;勾选多张卡片可以批量启用、禁用、移到分组或移到分组最前 / 最后。
- **用分组组织**:“战斗”“界面”“商店辅助”……每个分组有自己的名称和颜色,新建、编辑、删除、调整顺序都在分组列表上完成。删除含有模组的分组时,会让你选择这些模组去哪里,不会丢失。
- **改动可控**:移动或启用之后页面会提示“您有未保存的更改”,点击“保存更改”才会生效。

详见[模组与分组](/user-guide/mods-and-groups)。

## 模组更新后坏了,能看到改了什么、找回旧版本吗?

**答:打开“模组本地仓库”,SuperDucky 会为每个模组保存它出现过的每一个版本。**

![模组本地仓库页面:已归档模组的卡片列表](./img/screenshots/user-guide/mod-local-repository-list-zh-cn/original.avif)

- **自动归档**:来源包括 Steam 创意工坊和游戏本地的 `Mods` 文件夹。SuperDucky 按间隔(默认 60 分钟,可设 5 到 1440 分钟)比对模组,发现新版本就存下来,也可以随时点“立即检查”。
- **按内容区分版本**:每个版本由内容指纹标识,内容相同的重复比对不会产生新版本;时间记录的是 SuperDucky 归档它的时间,不是作者的发布时间。
- **更新改了什么,一目了然**:每个模组都有自己的版本历史,当前内容还没归档时会单独标注“尚未归档”。
- **已保存的版本不会被时间删除**:没有定时清理,也没有删除版本的操作;模组文件夹退回到某个已存过的版本时,直接复用那一份,不再重复存储。
- **不碰你的原始文件**:只从 Steam 文件夹和本地 `Mods` 文件夹复制,从不修改它们。
- **默认关闭,按游戏单独开启**:关闭期间不归档任何内容,也不运行定时比对。

它只负责保存和查看;把已保存版本放回模组文件夹的,只有“固化”的套件,而且只发生在启动时(见下文套件部分)。详见[模组本地仓库](/user-guide/mod-local-repository)。

## 加载顺序到底怎么定,启动前能先确认吗?

**答:拖动排序,再用“预览结果”看合并后的最终顺序。**

![预览结果:所有分组合并显示,卡片按分组着色](./img/screenshots/user-guide/duckov-load-order-zh-cn/original.avif)

- **规则很简单**:所有分组从上到下展开,每个分组内再从前到后排列,得到的这一条总顺序就是加载顺序,靠前的先加载,而且只有已启用的模组参与。
- **两个层级的调整**:拖动分组,整体移动这个分组里的模组;拖动分组内的卡片,只影响这一个分组。卡片菜单里还有上移、下移、移到分组最前 / 最后、发送到分组。
- **启动前确认**:点击“预览结果”,所有分组合并成一个列表,每张卡片带着所属分组的颜色。顺序有没有排对,启动游戏之前就能看到。
- **和日志对照**:游戏里各模组实际加载的先后,可以拿日志与预览结果对照。

以撒的结合没有加载顺序,只有启用与停用。详见[加载顺序与套件](/user-guide/load-order-and-profiles)。

## 想在不同玩法之间切换,怎么一键换整套模组?

**答:把每一种玩法存成一个“套件”,随时切换,还能后悔。**

![套件说明的“套件是什么”标签:套件记录启用的模组和加载顺序,换套件就是换整份清单](./img/screenshots/user-guide/suite-guide-zh-cn/original.avif)

- **套件是什么**:一整套模组配置,包括有哪些分组、每个模组是否启用、顺序是什么。“日常”和“测试”可以是两个互不影响的套件,切换套件只是整体替换这份清单,模组文件本身不会移动。
- **完整的管理操作**:新建(空白,或复制自已有套件)、重命名、切换、删除;至少保留一个套件,正在使用的套件不能删除。逃离鸭科夫还可以从 BML 的 `ModGroupConfig.json` 导入。
- **每次保存都留历史**:点击“还原历史记录”能看到每个版本的时间、分组数、模组数和已启用数量。还原只是先加载到编辑器里,检查没问题再保存;不满意就不保存,已保存的配置不会被改动。
- **固化**:打开后,每次启动前 SuperDucky 都会把套件里的模组比对并恢复到记录的版本;换不回时会拒绝启动,由你选择“修复并启动”“仍然启动”或“取消”。它依赖模组本地仓库。
- **绑定存档**:套件可以记下对应的存档名,方便区分。这只是一条记录,SuperDucky 不会复制、切换或改写存档。
- **各游戏的套件互相独立**。

详见[加载顺序与套件](/user-guide/load-order-and-profiles)。

## 创意工坊的模组怎么订阅、退订、保持更新?

**答:在“模组市场”里直接管理 Steam 创意工坊,不用再来回切浏览器。**

- **浏览与搜索**:默认显示热门模组;可以按关键词、标签或作者搜索,按相关度、最近更新、最高评分、最多订阅、最多下载等排序,在大图、普通、极简三种视图间切换。
- **订阅与退订**:一键订阅,Steam 负责下载;已订阅的模组显示“已订阅”,有新版本时显示“可更新”,点击即可更新;不需要了就点“退订”。订阅后回到模组管理点“刷新”,它就出现在“未分组”里。
- **订阅安全**:可以设置最低订阅人数(低于它的模组不出现在列表里,你已订阅的始终可见)、屏蔽指定作者、订阅前先确认订阅人数和作者历史记录。
- **自动更新**:自动检测已订阅模组的更新并触发下载,“更新历史”里可以查看记录。
- **和启动配合**:点击“启动游戏”时,SuperDucky 会先同步模组配置,再交给 Steam 启动游戏,并暂时让出自己的 Steam 连接,避免“游戏正在运行”的冲突。
- **拿到的是 ZIP 压缩包也行**:从一个文件夹里批量安装本地模组,会先检查模组标识,安装结果分为已安装、已替换、已跳过、失败。

详见[模组市场](/user-guide/marketplace)和[启动游戏](/user-guide/launching-the-game)。

## 依赖缺了、顺序反了,怎么发现并修好?

**答:页面顶部的依赖健康检查会替你盯着,并给出就地修复的按钮。**

- **五项检查**:依赖是否已安装、是否已启用、是否排在依赖它的模组前面、有没有循环依赖、是否同时启用了同名模组。
- **一眼看结果**:一切正常显示“模组配置健康”;有问题时横幅显示错误和警告的数量。
- **就地修正**:在报告里可以对缺失或未启用的依赖直接“启用”,或通过 Steam 订阅;用“定位依赖”和“定位本体”在列表里找到相关模组;确认没有影响的问题可以“忽略”,以后还能恢复。
- **市场里也能补**:模组详情的依赖面板会列出每个依赖是已安装、缺失还是未知,并能一次订阅缺失的依赖。

错误建议修复后再保存,警告则可以直接保存。详见[模组与分组](/user-guide/mods-and-groups#依赖健康检查)。

## 模组没生效,到底卡在哪一步?

**答:打开“日志系统”,实时读取游戏日志,不用自己找日志文件。**

![日志系统页面正在监控逃离鸭科夫的日志,列出每个模组的加载信息](./img/screenshots/user-guide/game-log-zh-cn/original.avif)

- 点击“开始监控”,新的日志行实时追加;可以搜索关键词、开启自动滚动,也能在编辑器里打开日志文件或打开所在文件夹。
- 按模组名搜索,查不到任何一行,往往说明游戏根本没有发现它;搜索 `error` 或 `exception`,出错信息通常紧挨着对应模组的加载记录。
- 三个游戏的日志位置不同,SuperDucky 会自己找到。

详见[游戏日志](/user-guide/logs)。

## 小结

| 你想做的事 | 用到的功能 | 一句话 |
|------------|------------|--------|
| 管好大量模组 | 模组管理与分组 | 统一列表、筛选搜索、批量操作、分组收拢 |
| 回看更新、保留旧版本 | 模组本地仓库 | 按内容指纹保存每个版本,不因时间删除 |
| 排对加载顺序 | 拖动排序与预览结果 | 启动前就看到合并后的最终顺序 |
| 在多套配置间切换 | 套件管理 | 复制、切换、历史还原、固化、绑定存档 |
| 管 Steam 创意工坊 | 模组市场 | 订阅、退订、更新、订阅安全、自动更新 |
| 修依赖问题 | 依赖健康检查 | 五项检查,就地启用或订阅,定位与忽略 |
| 查模组为何没加载 | 日志系统 | 实时监控、搜索、自动滚动 |

另外还有全屏的启动进度页面(可以中止启动)、首次启动的协议与快速检查、十种界面语言和亮暗主题。上面的用法不需要它们也能完成。

### 支持的游戏

每个游戏有自己独立的模组、套件和设置。SuperDucky 通过 Microsoft Store 和 GitHub Releases 发布,支持 Windows 10 / 11。

| 游戏 | Steam 应用 ID | 模组清单 | 说明 |
|------|--------------|----------|------|
| 逃离鸭科夫(Escape from Duckov) | 3167020 | `info.ini` | 默认游戏,功能最全 |
| 深空当铺(Probably Stolen) | 4348910 | `manifest.xml` | 启用模组时需要确认模组声明的能力,没有 NuGet 市场和存档图鉴 |
| 以撒的结合(The Binding of Isaac) | 250900 | `metadata.xml` | 没有加载顺序和能力确认,没有存档图鉴和 NuGet 市场;启用与停用通过模组文件夹里的 `disable.it` 实现 |

各游戏之间的差异见[深空当铺](/user-guide/probably-stolen)和[以撒的结合](/user-guide/isaac)。
