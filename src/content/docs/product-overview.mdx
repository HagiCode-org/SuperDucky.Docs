SuperDucky(中文名“超级丫丫”)是一款面向 Unity 游戏的桌面模组管理器。它负责添加、移除、启用和禁用模组,设置模组的加载顺序,并把每一套模组配置保存成**套件**,需要时一键切换。

它通过 Microsoft Store 和 GitHub Releases 发布,支持 Windows 10 / 11,每个游戏有自己独立的模组、套件和设置。

## 支持的游戏

| 游戏 | Steam 应用 ID | 模组清单 | 说明 |
|------|--------------|----------|------|
| 逃离鸭科夫(Escape from Duckov) | 3167020 | `info.ini` | 默认游戏,功能最全 |
| 深空当铺(Probably Stolen) | 4348910 | `manifest.xml` | 启用模组时需要确认模组声明的能力,没有 NuGet 市场和存档图鉴 |

两个游戏之间的差异见[深空当铺](/user-guide/probably-stolen)。

## 主要功能

![SuperDucky 模组管理页面:左侧是分组列表,右侧是已启用的模组卡片](./img/screenshots/user-guide/duckov-mods-zh-cn/original.avif)

- **模组管理**:扫描本地和 Steam 创意工坊的模组,一键启用或禁用,支持按来源、状态筛选和搜索。详见[模组与分组](/user-guide/mods-and-groups)。
- **分组与加载顺序**:把模组放进不同分组,拖动调整顺序;“预览结果”可以在启动游戏前看到所有分组合并后的最终顺序。详见[加载顺序与套件](/user-guide/load-order-and-profiles)。
- **套件和套件说明**:把当前的分组和启用状态保存成套件,在不同玩法之间切换;每次保存都会留下历史版本,可以还原。“套件说明”用三个示意动画解释套件、固化和绑定存档。
- **模组本地仓库**:为每个模组保存它出现过的每个版本,用来查看更新改了什么。默认关闭,在设置中按游戏打开;已保存的版本不会因为时间被删除。详见[模组本地仓库](/user-guide/mod-local-repository)。
- **全屏启动页面**:启动游戏时显示检查套件、检查模组文件、写入存档和交给 Steam 四个阶段,可以中止启动。详见[启动游戏](/user-guide/launching-the-game)。
- **首次启动的协议和快速检查**:第一次使用前阅读并同意协议(包括风险披露),再通过一次十题的快速检查。详见[首次启动](/quick-start/first-launch)。
- **扫描进度**:扫描模组时显示四个真实步骤和已用时间。详见[模组与分组](/user-guide/mods-and-groups)。
- **依赖检查**:自动检查依赖是否存在、是否已启用、顺序是否正确、有没有循环依赖,发现问题时在页面顶部提示。
- **模组市场**:浏览、订阅和取消订阅 Steam 创意工坊的模组,也可以从一个文件夹里的 ZIP 压缩包批量安装。详见[模组市场](/user-guide/marketplace)。
- **日志查看**:实时查看游戏日志,用来判断某个模组为什么没有加载。详见[游戏日志](/user-guide/logs)。
- **十种界面语言**,亮色和暗色主题。详见[设置](/user-guide/settings#显示语言)。
