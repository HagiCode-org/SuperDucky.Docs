第一次打开 SuperDucky 会先进入**系统设置**,然后才进入游戏的初始化向导。系统设置对所有游戏通用,只需要完成一次:选择显示语言、同意协议、通过快速检查。之后的向导只针对一个游戏:选择游戏,并告诉应用你的模组放在哪里。

## 1. 选择显示语言

在“选择显示语言”步骤选择界面语言。SuperDucky 支持十种语言,完整列表见[设置](/user-guide/settings#显示语言)。这一步之后可以随时在“设置 → 基础配置”里更改,更改立即生效。

## 2. 阅读并同意协议

协议共六项:年龄要求、公测声明、风险披露、终端用户许可协议、隐私政策和数据收集。

- 每一项都要**长按盖章**(按住按钮,或按住空格键或回车键)。盖章后,下一项会自动打开。
- 盖章前请阅读每一项的内容。盖章可以撤回,直到你点击继续。
- 全部协议盖章后,页面会提示可以继续,然后点击**同意并继续**。没有全部盖章时,页面会提示“请同意所有协议才能继续。”

![风险披露一项盖章后的协议页面](../img/screenshots/user-guide/first-run-disclosure-zh-cn/original.avif)

## 3. 通过快速检查

协议之后是一次十题的快速检查,用来确认你了解这个应用。

- 前三题是加法,两个加数和它们的和都在 0 到 100 之间。其余七题是关于 SuperDucky 的选择题。
- 每题四个选项,每次显示时选项顺序都会变化。
- 答错时该选项会被标记,题目保持不变,直到你选对为止。
- 十题全部答对后才能继续。通过后,这次检查不会再次出现,之后设置其他游戏时也不会再出现。

![快速检查的一道题:四个选项,顶部显示当前题号](../img/screenshots/user-guide/first-run-quiz-zh-cn/original.avif)

## 4. 选择游戏

游戏初始化的第一步是**选择游戏**。每个游戏各自初始化,只选你要用的那个即可;已经初始化的游戏会标注“已初始化”,没有初始化的标注“尚未初始化”。以后想管理另一个游戏时,再初始化它也可以。

## 5. 配置路径

“配置路径”一步要填写模组文件夹的位置:

| 路径 | 含义 |
|------|------|
| **本地 Mod 路径** | 你手动安装的模组所在的文件夹 |
| **Steam Mod 路径** | Steam 创意工坊自动下载的模组所在的文件夹 |
| **游戏数据路径 / 存档目录** | 用于把模组配置同步到游戏(逃离鸭科夫叫“游戏数据路径”,深空当铺叫“存档目录”) |

最省事的做法是点击**自动探测路径**。如果游戏是通过 Steam 安装的,SuperDucky 会尝试自动找到这些文件夹;探测后请检查一遍是否正确。也可以点击文件夹图标手动选择。至少需要配置本地 Mod 路径才能继续。设置页面里同样的两项叫“本地 Mod 文件夹”和“Steam Workshop 文件夹”。

各个游戏的默认位置如下:

| 游戏 | 本地模组 | 游戏数据 |
|------|----------|----------|
| 逃离鸭科夫 | 游戏目录下的 `Duckov_Data/Mods` | `%UserProfile%\AppData\LocalLow\TeamSoda\Duckov\` |
| 深空当铺 | 游戏目录下的 `Mods`,每个模组一个子文件夹,里面有 `manifest.xml` | `%UserProfile%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\` |

## 6. 完成

最后一页列出了主要功能,点击**完成并开始使用**即可。向导之后,路径随时可以在“设置”里修改。
