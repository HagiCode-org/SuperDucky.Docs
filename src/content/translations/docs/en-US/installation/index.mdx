You can get SuperDucky from the **Microsoft Store**, or download the latest and earlier versions from **GitHub Releases**. Windows installs and updates the Store version for you, and you do not need to install Node.js or any other runtime first.

## Get it

| Item | Details |
|------|---------|
| Where | Microsoft Store, or [GitHub Releases](https://github.com/HagiCode-org/SuperDucky.Release/releases) |
| Store ID | `9NDBTDKQBX30` |
| Name in the Store | "超级丫丫" in Chinese, SuperDucky in English |
| System | Windows 10 / 11 |

1. Open the Microsoft Store and search for "SuperDucky" (or "超级丫丫"), or open the page with Store ID `9NDBTDKQBX30` directly.
2. Click **Get** and wait for the installation to finish.
3. Start SuperDucky from the Start menu.

## Download the latest and earlier versions from GitHub

Besides the Microsoft Store, you can download any version, including the latest and earlier ones, from the releases page of [SuperDucky.Release](https://github.com/HagiCode-org/SuperDucky.Release/releases).

1. Open [https://github.com/HagiCode-org/SuperDucky.Release/releases](https://github.com/HagiCode-org/SuperDucky.Release/releases).
2. Pick the version you want. The top entry is the latest; older entries are the history.
3. Download the installer from the version's **Assets** and run it.

A version downloaded from GitHub is not updated by the Microsoft Store. When you want a newer version, come back to the releases page. Changes in each version are in the [release notes](/en-US/release-notes).

## Updates

The Store version is updated automatically. You can also check by hand under "Library" in the Microsoft Store. A version downloaded from GitHub has to be updated by getting the new version from the [releases page](https://github.com/HagiCode-org/SuperDucky.Release/releases). Changes in each version are in the [release notes](/en-US/release-notes).

## After installing

- The first launch opens the setup wizard; see [First launch](/en-US/quick-start/first-launch).
- Settings, profiles and caches are kept in the app's data folder. The exact location is shown under "Settings → Basic → Config and data location"; see also [Telemetry and privacy](/en-US/faq/data-and-privacy). Each game's data lives under `games/<game>/` there, separate from the others.

## Requirements

- The game you want to manage (Escape from Duckov, Probably Stolen or The Binding of Isaac) installed through Steam.
- The Steam client running, if you want to subscribe to Workshop mods in the marketplace.
