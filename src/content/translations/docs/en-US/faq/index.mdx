## Which games and platforms are supported?

Escape from Duckov and Probably Stolen. SuperDucky is released through the Microsoft Store and GitHub Releases (the latest and earlier versions are on GitHub) and runs on Windows 10 / 11. See [Download and install](/en-US/installation).

## Do the mods of the two games affect each other?

No. Each game has its own mod paths, profiles, groups and caches, stored under `games/<game>/` in the user data folder. Switching games switches the whole app to that game's data.

## I enabled a mod but it does nothing in the game

Check in this order; the full steps are in [Mod not loading](/en-US/faq/mod-not-loading):

1. Did you click **Save changes** after the change?
2. Did you start through SuperDucky's **Launch game** button? (For Probably Stolen, the save is written only then.)
3. Does the "Mod configuration is healthy" banner show a dependency error?
4. Search the mod name in the [game log](/en-US/user-guide/logs).

## Steam says "game is running" after I click Launch game

When launching from SuperDucky, it briefly turns off its own Steam connection. If the wait is too short, the connection has not been released and Steam thinks the game is already running. Increase **Game launch wait time** in "Settings → Game options"; reference values are in [Settings](/en-US/user-guide/settings).

## Why does Probably Stolen ask me to confirm capabilities?

Only a **newly enabled** mod that declares capabilities, or an already enabled mod that **adds** a capability you have not approved, triggers the dialog. Each mod needs its own checkbox, there is no "approve all", and approvals are not remembered. Cancelling writes nothing. See [Probably Stolen](/en-US/user-guide/probably-stolen).

## Probably Stolen says it is running and asks me to close it

SuperDucky never edits the save while the game runs. Close the game and launch again. If the game is closed but you still see this, the process check failed and SuperDucky safely assumes the game is running; wait a moment or restart SuperDucky and retry.

## My Workshop mod is missing from Mod Management

Click **Refresh** to rescan, and check that the Steam Workshop folder path in "Settings → Game options" is correct. A mod you just subscribed to must finish downloading in Steam first.

## Where is my data, and is it uploaded?

See [Telemetry and privacy](/en-US/faq/data-and-privacy).

## What happens if I abort a launch?

Abort only takes effect at safe points, and after a successful abort the game does not start. A save that was already written stays, with its backup file next to it. Once the game has been handed to Steam, an abort only stops the wait; Steam may still open the game. See [Launching the game](/en-US/user-guide/launching-the-game).

## Will the Mod Local Repository take a lot of space, and is it deleted automatically?

The page shows the **Repository size** in use. SuperDucky does not delete archived versions because of their age, and there is no action that deletes an archived version. See [Mod Local Repository](/en-US/user-guide/mod-local-repository).

## Which languages does the interface support?

Ten: 简体中文, 繁體中文, English (US), 日本語, 한국어, Deutsch, Français, Español, Português (Brasil) and Русский. Change the language in Settings; the change takes effect right away. Details are in [Settings](/en-US/user-guide/settings#display-language).

## Where do I report problems?

Open an issue on [GitHub Issues](https://github.com/ducky7go/SuperDucky/issues). Attaching the log exported from "Settings → Debug tools" makes it much easier to find the cause.
